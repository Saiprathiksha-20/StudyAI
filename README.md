# 📚 StudyAI – AI Powered Study Assistant

StudyAI is a modern AI-powered web application built for students to manage study materials, upload PDFs, and use AI-based learning tools. The project is designed with a clean UI and practical productivity features for students.

#  Features

## 🔐 Authentication System

* User Signup and Login
* Firebase Authentication integration
* Protected routes for secure access
* Logout functionality

## 📄 Study Material Library

* Upload PDF notes and study materials
* Store uploaded PDFs using Cloudinary
* View uploaded PDFs anytime
* Personal study resource collection

## 🤖 AI Notes Summarizer

* Generate summaries using AI
* Uses Groq API integration
* Fast AI responses
* Simplifies lengthy study notes

## 🧠 Additional Learning Modules

* Quiz Section
* Flashcards Section
* Dashboard UI
* Modern responsive design

# 💡 Project Purpose

StudyAI was developed to create a smarter and more interactive learning experience for students by combining modern web technologies with AI-powered tools. The platform focuses on simplifying the process of managing study materials, improving productivity, and making learning more efficient through automation and intelligent assistance.

The project demonstrates practical implementation of:

* Frontend development using React.js
* Authentication systems with Firebase
* Cloud-based file storage using Cloudinary
* AI integration using Groq API
* Responsive UI/UX design principles
* Real-world API handling and asynchronous operations

StudyAI is designed not only as a learning tool for students but also as a full-stack portfolio project that showcases modern development practices, cloud integration, and AI-powered functionality.
